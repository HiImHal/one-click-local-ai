# One Click Local AI (free edition) v0.8.0

**[Get the full version at hiimhal.com](https://www.hiimhal.com)**

A free one-click installer for Windows PCs with AMD graphics. It installs **YuE2**, which generates music locally: it writes full songs (vocals and music) from your lyrics, entirely on your own PC, with no NVIDIA GPU and no cloud.

In this free edition only the YuE2 music pack can be installed. The other packs are listed in the app as *Coming in a future version*.

## System requirements
- Windows 11, 64-bit
- AMD Ryzen AI Max PC with Radeon 8060S / 8050S graphics (for example 96 GB or 128 GB mini PCs)
- AMD Adrenalin driver 26.1.1 or newer
- AMD Variable Graphics Memory of at least 32 GB, 48 GB recommended (the installer checks this and shows you how to change it)
- About 40 GB free disk space and an internet connection

## Install
1. Download `OneClickLocalAI-Setup-0.8.0-public.exe` from the [Releases](../../releases/latest) page (check it against `SHA256SUMS.txt` if you like).
2. Run it. The installer is not code-signed, so Windows SmartScreen shows **"Unknown publisher"** / "Windows protected your PC". Click **More info** > **Run anyway**. Some antivirus programs may also flag it; this is a false positive.
3. Open **One Click Local AI** from your Desktop.
4. Click **Install** on the **YuE2 music pack** and follow the setup window. You must accept the YuE2 licence. Downloads take a while; if interrupted, run it again and it continues where it stopped.
5. When done, open **YuE2 song generator (One Click)** from your Desktop. Songs are saved in `Music\YuE2-OneClick`.

Uninstall: Start menu > One Click Local AI > Uninstall (your songs are kept).
